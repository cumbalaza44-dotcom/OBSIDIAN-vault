## 🔬 Investigación
**Pregunta del día:** ¿Qué implica que Figma convierta el código en material de diseño nativo (Code Layers + Motion + Agent MCP) y cómo cambia el flujo de branding y prototipado?

**Fuentes:**
- [Config 2026 Recap — Figma Blog](https://www.figma.com/blog/config-2026-recap/)
- [4 ways we're using our MCP server at Figma](https://www.figma.com/blog/4-ways-were-using-our-mcp-server-at-figma/)
- [Code on the Figma Canvas](https://www.figma.com/blog/code-on-the-figma-canvas/)

**Hallazgos:**
- Figma introduce **Code Layers**: cualquier capa de diseño se convierte en código interactivo con un clic. Se puede duplicar, iterar y comentar como cualquier frame.
- **Figma Motion** añade línea de tiempo con keyframes directamente en el canvas — sin salir a After Effects.
- El **Figma MCP Server** ahora funciona en Slides, FigJam y Make, permitiendo crear/actualizar decks, boards y prototipos desde un prompt.
- El **Figma Agent** puede leer Slack, Google Drive y Release Notes para actualizar decks vivos automáticamente.

## 🛠️ Creación
**Micro-proyecto:** Prototipo de brand kit interactivo con Code Layers
**Qué hice:** Diseñé un flujo conceptual de cómo un brand kit (colores, tipografía, componentes) se beneficiaría de Code Layers: el diseñador define la guía visual, el code layer renderiza el componente funcional en vivo — sin traducción diseño→código.
**Resultado:** Mapa mental de flujo de trabajo unificado diseño→código→diseño
**Qué aprendí:** La separación diseño/código era una limitación de herramientas, no de naturaleza. Code Layers cierra el círculo.

## 🧩 Conexiones
- **Tech → Branding:** Code Layers permiten prototipar componentes de marca funcionales (botones, cards, navegación) sin salir del canvas de diseño.
- **E-commerce:** Un brand kit con code layers vivos acelera la creación de landing pages y emails transaccionales.
- **Video:** Figma Motion compite directamente con flujos básicos de motion graphics que antes requerían After Effects.
