## 🔬 Investigación
**Pregunta del día:** ¿Cómo funciona Mesh LLM y qué implica para la computación distribuida de IA?
**Fuentes:**
- [Mesh LLM — iroh.computer](https://www.iroh.computer/blog/mesh-llm)
- [Hacker News — 258 points](https://news.ycombinator.com/)

**Hallazgos:**
- Mesh LLM pool GPUs y memoria de múltiples máquinas en una sola API compatible con OpenAI
- Usa iroh para networking: hole-punching, NAT traversal, QUIC directo entre nodos
- "Skippy" split mode: particiona modelos 235B+ por capas, distribuidos en varias máquinas modestas
- Cualquier cliente OpenAI habla con localhost:9337, sin importar dónde corre el modelo
- Catálogo de 40+ modelos, desde 500M params (laptop) hasta 235B MoE (malla)

---

## 🛠️ Creación
**Micro-proyecto:** Diagrama conceptual de Mesh LLM y su arquitectura
**Qué hice:** Diseñé un diagrama de la arquitectura de Mesh LLM mostrando cómo se distribuyen modelos entre nodos, el flujo de requests, y el split mode "Skippy"
**Resultado:** Un diagrama claro que ilustra la diferencia entre ejecución local, routing a peer, y split pipeline
**Qué aprendí:** La computación distribuida de IA no requiere hardware centralizado; la clave es la orquestación de nodos con networking descentralizado
