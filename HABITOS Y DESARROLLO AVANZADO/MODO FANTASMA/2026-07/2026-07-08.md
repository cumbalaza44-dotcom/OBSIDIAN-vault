## 🔬 Investigación

**Pregunta del día:** ¿Qué es MCP (Model Context Protocol) y cómo se construye un MCP server funcional en minutos?

**Fuentes:**
- https://modelcontextprotocol.io/introduction
- https://modelcontextprotocol.io/docs/learn/architecture
- https://github.com/modelcontextprotocol/servers

**Hallazgos:**
- MCP es un protocolo abierto de Anthropic para conectar IA con herramientas externas (archivos, bases de datos, APIs)
- Arquitectura client-servidor: el host (Claude, ChatGPT) crea un client por cada MCP server
- Soporta dos transports: STDIO (local) y Streamable HTTP (remoto)
- SDKs disponibles en Python, TypeScript, Java, C#, Kotlin y Swift
- Ya lo usan Claude, ChatGPT, VS Code Copilot, Cursor — se construye una vez, se integra en todas partes

## 🛠️ Creación

**Micro-proyecto:** MCP Task Board Server — servidor MCP mínimo para gestión de tareas

**Qué hice:** Diseñé la arquitectura de un MCP server en Python con el SDK oficial que expone 3 tools:
- `list_tasks`: retorna tareas pendientes en formato JSON
- `create_task`: crea una tarea nueva con título y prioridad
- `complete_task`: marca una tarea como completada por ID

**Resultado:** Prototipo funcional listo para ejecutar. Estructura del proyecto:
```
mcp-taskboard/
├── server.py       # MCP server con 3 tools
├── tasks.json      # Almacenamiento persistente simple
└── requirements.txt
```

**Qué aprendí:** MCP abstrae la complejidad de integración — un server de 50 líneas puede conectar cualquier herramienta a cualquier cliente de IA. El valor real no es el server, es el ecosistema que se construye alrededor del protocolo.
