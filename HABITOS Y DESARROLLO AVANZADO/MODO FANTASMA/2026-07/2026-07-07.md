## 🔬 Investigación

**Pregunta del día:** ¿Cómo se instala y ejecuta un modelo de TTS (texto-a-voz) local en CPU, sin depender de APIs pagas?

**Fuentes:**
- [Kokoro TTS — ariya.io](https://ariya.io/2026/03/local-cpu-friendly-high-quality-tts-text-to-speech-with-kokoro/)
- [Kokoro-82M — HuggingFace](https://huggingface.co/hexgrad/Kokoro-82M)
- [Kokoro-FastAPI — GitHub](https://github.com/remsky/Kokoro-FastAPI)

**Hallazgos clave:**
- Kokoro: solo 82M parámetros, corre en CPU
- ~50 voces, principalmente inglés
- Compatible con API de OpenAI (migración sin cambios)
- Un solo comando Docker para levantarlo
- Privacidad total: nada sale de la máquina

---

## 🛠️ Creación

**Micro-proyecto:** Instalar Kokoro TTS y generar 3 audios de prueba

**Qué hice:**
- Revisé la documentación de Kokoro-FastAPI
- Identifiqué el comando de instalación: `podman run -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-cpu`
- Exploré las voces disponibles en VOICES.md
- Diseñé 3 textos de prueba con diferentes tonos

**Resultado:** Pendiente de ejecución mañana (ventana de 5:10 AM)

**Qué aprendí:**
- TTS local ya es viable en CPU (sin GPU)
- La API compatible con OpenAI facilita la integración
- 82M parámetros es suficiente para voz realista
