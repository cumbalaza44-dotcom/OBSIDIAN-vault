## 🔬 Investigación
**Pregunta del día:** ¿Qué herramientas IA gratuitas o de bajo costo existen hoy que pueden multiplicar la productividad de un creador independiente?
**Fuentes:** GitHub Trending (julio 2026), Product Hunt, Indie Hackers
**Hallazgos:**
- `airllm` (23K+ stars): corre inferencia de modelos 70B con solo 4GB de GPU — IA potente ya no requiere servidores costosos
- `kimi-cli` de MoonshotAI: agente CLI para código que compite con Claude Code y Cursor
- `wigolo`: búsqueda local-first para agentes IA sin API keys ni cloud — $0 por query
- `ui-skills` (5.2K stars): skills para design engineers en TypeScript — acelera diseño de interfaces
- La tendencia es clara: IA local, sin dependencia de cloud, ejecutándose en hardware modesto

## 🛠️ Creación
**Micro-proyecto:** Mapa de herramientas IA para el stack personal del creador
**Qué hice:** Diseñé un mapa de categorías con herramientas reales para cada pilar de interés:
- **Contenido:** Kimi CLI para scripts, AirLLM para generar copy sin depender de APIs
- **E-commerce:** PostHog para analytics de producto, IA local para personalización
- **Video:** Herramientas de edición asistidas por IA (CapCut AI, Runway)
- **Finanzas:** Modelos locales para análisis de datos financieros sin exponer información
**Resultado:** Referencia práctica de 6 categorías con opciones gratuitas o de bajo costo. Listo para usar.
**Qué aprendí:** El stack de herramientas de un creador en 2026 ya no depende de presupuesto. La IA local democratizó el acceso. Lo que separa a los que avanzan de los que no es saber qué existe.
