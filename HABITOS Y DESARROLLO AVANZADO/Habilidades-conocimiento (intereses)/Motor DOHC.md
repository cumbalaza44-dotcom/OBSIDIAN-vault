# 🔧 Funcionamiento Mecánico — Motor DOHC

**DOHC** = *Double Overhead Camshaft* (Doble Árbol de Levas a la Cabeza)

## ⚙️ Componentes principales

| Componente | Función |
|-----------|---------|
| **2 árboles de levas** | Uno para admisión, otro para escape |
| **16 válvulas** (4 por cilindro) | 2 admisión + 2 escape |
| **Cadena/correa de distribución** | Sincroniza cigüeñal con árboles |
| **Tensores hidráulicos** | Mantienen tensión de la cadena |
| **Levantadores hidráulicos** | Compensan juego de válvulas automáticamente |

## 🔄 Ciclo de 4 tiempos

```
1. ADMISIÓN  → Válvulas de admisión abren → pistón baja → entra mezcla
2. COMPRESIÓN → Ambas válvulas cerradas → pistón sube → comprime mezcla
3. EXPLOSIÓN  → Bujía enciende → expansión fuerza pistón abajo
4. ESCAPE     → Válvulas de escape abren → pistón sube → expulsa gases
```

## 🏎️ Ventajas del DOHC

- ✅ Mayor flujo de aire (4 válvulas por cilindro)
- ✅ Mejor rendimiento en altas RPM
- ✅ Ángulos de válvula optimizados (admisión y escape independientes)
- ✅ Mayor eficiencia volumétrica
- ✅ Admite sistemas VVT (Variable Valve Timing) más fácilmente

## 🔧 Mantenimiento clave

1. **Cadena de distribución** — Revisar tensión cada 60,000 km
2. **Ajuste de válvulas** — Cada 40,000 km (en motores sin hidráulicos)
3. **Cambio de aceite** — Cada 5,000 km (fundamental para los tensores)
4. **Tapas de válvulas** — Verificar sellos para evitar fugas de aceite
